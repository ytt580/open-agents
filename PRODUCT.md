# PRODUCT.md - Open-Agents

## Product Identity

**Open-Agents** is an AI automation platform for lead prospecting, scraping, site creation, and proposal sending. It empowers users to create autonomous AI agents that work 24/7 to generate leads, build websites, and send personalized proposals.

## Target Audience

- **Primary:** Small business owners and freelancers who need automation for sales and marketing
- **Secondary:** Marketing agencies and sales teams looking to scale outreach
- **Technical Level:** Non-technical users who want simple chat-based automation

## Core Value Proposition

"Your agents search for leads, create sites, send proposals, and close deals. You just define the objective."

## Product Modes

### Landing Page (Persuade)
- Convert visitors to users
- Show agent capabilities and live demos
- Present clear pricing (Free vs Premium)

### Dashboard (Operate)
- Manage flows and automations
- Configure API keys and skills
- Monitor agent performance

### Flow Editor (Operate)
- Chat-based flow creation
- Visual step management
- Real-time execution monitoring

## Brand Voice

- **Tone:** Professional yet approachable, technical but not intimidating
- **Language:** Portuguese (pt-BR) primary
- **Style:** Direct, action-oriented, emphasizing automation and results

## Key Features

1. **AI Agents:** Autonomous agents that execute tasks
2. **Lead Prospecting:** Google Maps scraping and lead qualification
3. **Site Creation:** Automated website generation
4. **Email/WhatsApp Outreach:** Personalized proposal sending
5. **Flow Automation:** Visual workflow builder
6. **Skills System:** Extensible automation capabilities
7. **Multi-AI Support:** GPT-5, Kimi K3, and other models

## Pricing

- **Free:** GPT-5 model, unlimited agents and tasks
- **Premium (R$10/mo):** Kimi K3 model, same features

## Technical Stack

- **Frontend:** Next.js 14, React, Tailwind CSS
- **AI:** Bluesminds API (Kimi K3, GPT-5)
- **Deployment:** Render (auto-deploy from GitHub)
- **Storage:** localStorage for flows (backend planned)

## Success Metrics

- User activation (first flow created)
- Agent execution count
- Lead generation volume
- Site creation rate
- Proposal response rate
